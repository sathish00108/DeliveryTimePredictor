# Delivery Time Predictor

A machine-learning web application that predicts the delivery time (in minutes) for e-commerce orders based on agent attributes, weather, traffic, location distance, and order category.

## Problem Type
**Regression** — `Delivery_Time` (minutes) is the continuous target variable.

## Dataset
`data/dataset.csv` — 43 000+ real delivery records with features:
`Agent_Age`, `Agent_Rating`, `Weather`, `Traffic`, `Vehicle`, `Area`, `Category`, store/drop coordinates, order & pickup timestamps.

## Feature Engineering
| Feature | Description |
|---|---|
| `Distance_km` | Haversine distance between store and drop location |
| `Prep_Time_min` | Minutes between order placed and pickup |
| `Day_of_Week` | Day index (0 = Monday) |
| `Hour_of_Day` | Hour the order was placed |

## Models Compared
- Ridge Regression
- Random Forest Regressor
- Extra Trees Regressor
- Gradient Boosting Regressor

The best-performing model (lowest MAE on the hold-out test set) is saved to `models/model.pkl`.

## Local Setup

### 1. Clone / open the project
```bash
git clone <your-repo-url>
cd project
```

### 2. Create a virtual environment (recommended)
```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Train the model
```bash
python train_model.py
```
This will print model comparison results and save `models/model.pkl`.

### 5. Launch the Streamlit app
```bash
streamlit run app.py
```
Open [http://localhost:8501](http://localhost:8501) in your browser.

## Streamlit Community Cloud Deployment

1. Push the **entire `project/` folder** (including `data/dataset.csv`) to a public GitHub repository.
2. Go to [share.streamlit.io](https://share.streamlit.io) and click **New app**.
3. Select your repository, branch, and set **Main file path** to `app.py`.
4. **Important:** Add a startup command so the model is trained before the app starts.  
   Create `.streamlit/config.toml` (already included) or add a `packages.txt` if system deps are needed.  
   Alternatively, add a `setup.sh`:
   ```bash
   python train_model.py
   ```
   and set it as a pre-run command in your Streamlit Cloud settings.

> **Tip:** If you commit a pre-trained `models/model.pkl` to the repo, the app starts immediately without needing to retrain.
